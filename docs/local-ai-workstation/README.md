# Historical local-agentic-dev material

This directory is archived reference material from the former OpenCode + Ollama workstation experiment. It is not part of the supported setup and its scripts must not be used for installation, runtime selection, or benchmarking.

The supported local path is documented in the repository root:

```sh
./doctor.sh
./install.sh
little-coder
```

The supported runtime is Little Coder + Rapid-MLX on `127.0.0.1:8000` with the local Nail Qwen3.6-35B-A3B MLX model. This archive is retained for historical measurement context only. Cleanup does not delete the Nail model cache or independently installed packages.
