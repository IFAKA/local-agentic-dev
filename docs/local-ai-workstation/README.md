# Historical local-agentic-dev material

This directory is archived reference material from the former OpenCode + Ollama
workstation experiment. It is not part of the supported setup and its scripts
must not be used for installation, runtime selection, or benchmarking.

The sole supported local path is documented in the repository root:

```sh
./doctor.sh
./install.sh
pi --offline
```

The supported runtime is Pi + Rapid-MLX on `127.0.0.1:8000` with
`mlx-community/Qwen3.6-35B-A3B-nvfp4`. This archive is retained for historical
measurement context only. The cleanup scripts do not uninstall or delete any
independently installed OpenCode, Ollama, Aider, or model caches.
